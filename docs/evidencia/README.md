# Evidencia de funcionamiento

Aquí se guardan las capturas y los videos cortos de cada entrega.

Organización sugerida:

```
docs/evidencia/entrega-1/   login, bloqueo de rutas, dashboard
docs/evidencia/entrega-2/   vehículos, conductores, indicadores
docs/evidencia/entrega-3/   rutas, mapa, aplicación en la URL pública
docs/evidencia/entrega-4/   programación, dashboard final, video de demostración
```

Cada carpeta debe incluir las instrucciones para verificar lo que se muestra. La evidencia tiene que corresponder exactamente al código del release de esa entrega.
